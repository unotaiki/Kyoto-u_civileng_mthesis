\section{フィールドデータにおける評価検証}\label{sec:eval_field}

本節では、\cref{chap:experiments}に従い宇治川中流域の副流Area1(\cref{sec:field-dataset})を対象に行った、RA-GSの2DGSによる屈折を排した三次元再構成の結果に関して述べる。
最適化後のGaussian数はおよそ900k個であり、Gaussian Splattingの最適化に要する時間は約2時間であった。

本節では、提案手法の実用可能性を示すため、一般に水深写真測量のパイプラインで使用されるMVS(COLMAPによる実装\cite{Schonberger2016ECCV_PatchMatchStereo})と補正を行わない場合の2DGSに関して、2DGSに関し提案手法を適用したRA-GSとの結果を比較する。

\cref{fig:eval_field_cray}に示すように、RA-GSによる再構成結果は、2DGS(補正無し)に比べて、より深い位置に形状を復元している。
これは、正確に屈折を考慮した補正が適用され、見かけの浅さの影響が除外できているからであると考えられる。
2DGSでも、強力なSurface正則化が適用されているため、大部分で水底は滑らかに表現されているが、画像手前の特に深度の大きい部分には一部、本来は存在しない浮遊アーティファクトが存在している。
このアーティファクトは、補正を行わない場合、屈折による外観の歪みに対して整合性をもって空間を表現できないために生じると考察できる。
一方、RA-GSでは、屈折の明示的モデル化によりシーンに測光的な一貫性を確保できるため、水底全体でノイズの少ない再構成ができている。
\kobayashi{↑図の浮遊アーティファクトの原因の考察を追加}

また、\cref{fig:eval_field_render}に示すように、RA-GSから再構成したGaussian Splattingモデルは、屈折の影響を排した高精細な外観情報を保持している。
専用のViewerを用いることでインタラクティブかつリアルタイムに視認できるため、エコトーン環境において生物の痕跡を探索したり、調査地の状態を詳細に記録・共有するための強力なツールとなる。
屈折の影響がないため、実スケールでの粒径分析などの用途にも転用可能である。

\cref{fig:eval_field_voxel_height}は、COLMAPによるMVS実装\cite{Schonberger2016ECCV_PatchMatchStereo}を比較に加え、深度を色で明示している。
形状が分かりやすいように各構成結果を\qty{8}{cm}単位のボクセル(Voxel)で区切り、水面下の形状を深度が大きくなるに従い青色から赤色にかけてのカラーランプで表示している。
COLMAP MVSでは、最もノイズの散乱した再構成結果になった。
水底部から水面にかけて一様にノイズが散乱するように点群が生成されており、水底部の幾何情報を抽出するのは難しい。
2DGSでは、最深部でも50cm程度の深度で再構成されている。
最深部が水底1m程度であることを考慮すると、大きく水深は過小評価されている。

RA-GSでは、定量評価(\cref{subsec:eval_field_quantitative})で後述するように、幾何的に正確な水底を含めた三次元再構成ができている。
浮遊植物によりオクルージョンとなっている部分が無ければ、流体シミュレーションなどの用途へも容易に転用できるデータを得ることができる。



\paragraph{定量評価}\label{subsec:eval_field_quantitative}

\cref{sec:field-dataset}で示したPoint 1, Point 2を対象に、再構成メッシュから深度を手動で計測し、定量的に評価した。
ターゲットの座標の真値は不明なので、再構成メッシュのテクスチャからターゲットを見つけ出すことで計測を行った。
RA-GSのワークフローでは、高解像度な外観情報を含有するメッシュを出力できるため、数cmのターゲットを明確に確認することができた。
計測はCloudCompare\cite{girardeau2016cloudcompare}上で行い、メッシュに対して各計測点の深度を読み取った。
CloudCompare上での計測を\cref{fig:eval_field_cloudcompare_depth}に示す。

\cref{tab:eval_field_depth}に、現地での実測値(Measured)と、メッシュから読み取った推定値(Estimated)、およびその差(Error)を示す。
Relative Errorは撮影高度\qty{12}{m}に対する相対誤差である。
Point 1, Point 2に対する実測値はそれぞれ、\qty{61.0}{cm}および\qty{71.0}{cm}であるのに対し、その推定値はそれぞれ、\qty{60.7}{cm}および\qty{70.7}{cm}であり、その差はそれぞれ、\qty{0.3}{cm}および\qty{0.3}{cm}であった。
% \note{Point 1: 59.4, 61.0, 61.0, 61.4, ave60.7}
% \note{Point 2: 71.3, 70.7, 70.3, 70.5, ave70.7}
なお、座標を一意に決めることはできず、推定値はターゲット付近でサンプリングする位置に依存する。
今回、ターゲットは水底に垂直に突き刺すように設置し、その底からの深度を計測しているため、
再構成データからの推定値の計測には、ターゲットを中心とした四方の4点をサンプリングした深度の平均値を用いた。
\[
\begin{aligned}
\mathrm{Point\ 1}:~&(59.4,~61.0,~61.0,~61.4) \rightarrow \mathrm{平均値};60.7\\
\mathrm{Point\ 2}:~&(71.3,~70.7,~70.3,~70.5) \rightarrow \mathrm{平均値};70.7
\end{aligned}
\]

\kobayashi{COLMAP MVS と、補正を行わないGaussian Splattingによる水底の深度を求めた定量評価を追加}
同様に、COLMAP MVSと2DGSによる再構成結果による深度、およびその屈折補正値を算出し比較を行った。
深度はRA-GSと同様に、再構成後のメッシュから読み取り、四方をサンプリングした深度の平均値を用いた。
それぞれの補正は、水深に屈折率$n=1.33$を乗じる\cite{westaway2001_PhotograBathy-multiply-n,Woodget2014_PhotograBathy-multiply-n}を適用している。
結果を\cref{tab:depth_error_comparison}に示す。

RA-GSにおいては、高度12mに対する最大相対誤差は0.025\%であり、これはDietrichらの手法\cite{Dietrich2016_multi-angle-correction}0.02\%に匹敵する精度である。
COLMAP MVSによる深度補正結果は、RS-GSに次いで高精度であり、0.27\%ほどの相対誤差での再構成が示されている。
しかしながら、RA-GSより10倍程度の誤差が大きく、深度が過小評価される傾向がある。
これは、MVSによる結果に単純な深度補正を乗じるだけでは、屈折の影響をMVSの原理を通して除外できていないためであると考えられる。
このことは、2DGSによる結果でも同様で、三次元再構成のアルゴリズム中に明示的に屈折の影響を除外するRefractive-Awareな手法の重要性を示唆している。

% 加えて、Dietrichらの手法では特徴点抽出に依存していたが、RA-GSではワークフローとして密な幾何情報を河床全域に対して抽出できている。
結論としては、検証点が少なく、統計的な有意を確かめることはできないが、カメラアライメントや水面の抽出にmm級の誤差が存在し得ることを踏まえても、RA-GSの屈折モデル化は実環境においても正確に屈折の影響を除外した密な三次元再構成ができることが分かる。
