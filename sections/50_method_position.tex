本研究では、屈折を含む画像群から、屈折の影響を除外する三次元再構成手法として、Refractive-Aware Gaussian Splatting(RA-GS)を提案する。
RA-GSでは、空気と水面の境界におけるスネルの法則に基づく光の屈折を考慮し、水中の真の位置に存在する三次元Gaussianのパラメータを、カメラから観測される屈折により生じる「見かけの位置」へと補正する。

\cref{sec:prelim_inverse-rendering-as-3d-reconstruction}で述べたように、微分可能レンダリングによる逆レンダリングを用いてた本研究では、Analysis-by-Synthesisのアプローチを採用する。
水中シーンにおいて、観測画像 $I_{obs}$ は屈折による幾何学的歪みを含んでいる。
従来の3D Gaussian Splattingのように、レンダリング関数 $R$ が「空気中」のみを仮定している場合、最適化プロセスは シーンパラメータによるレンダリング画像$R(\Theta)$ を歪んだ $I_{obs}$ に無理やり適合させようとする。
その結果、推定されるシーンパラメータ $\Theta$(各Gaussianの位置や形状)自体が、屈折による歪みを再現するために誤った位置（見かけの位置）へと更新されてしまう。
これは、物理モデルの欠如を幾何形状の歪みで補完している状態である。

対して本手法では、レンダリング過程に屈折モデルを組み込むことで、レンダリング関数 $R$ を「屈折を考慮したレンダリング関数 $R_{refr}$」へと拡張していると解釈できる。
本手法における最適化は、以下の整合性を保つように行われる:
  
\[
  \textbf{シーンパラメータ(真の形状)}\ \Theta_{\mathrm{real}}
  \xrightleftharpoons[]{\text{屈折補正変換}}
  \textbf{見かけのシーン}\ \Theta'
  \xrightleftharpoons[]{\text{透視投影}}
  \textbf{レンダリング画像}\ I_{\mathrm{pred}}
\]
    
このプロセスにより、レンダリング画像 $I_{pred}$ は物理的に正しい屈折効果を含んだ状態で生成される。
この $I_{pred}$ と、同様に屈折を含んだ観測画像 $I_{obs}$ との間の観測誤差を最小化するように逆伝播を行うことで、勾配は「見かけの形状」ではなく、変換前の「真の形状 $\Theta_{real}$」へと正しくフィードバックされる。

RA-GSでは、真の位置にあるGaussianに対し、視点に応じた屈折歪みの影響を反映するため、物理法則に基づく以下の3つのパラメータ変換を導入する:
\begin{itemize}
  \item \textbf{位置補正}:スネルの法則に基づき、真の三次元位置から観測される見かけの位置への変換を行う(\cref{sec:position-correction})。
  \item \textbf{共分散行列（形状）補正}:屈折による空間の圧縮を考慮し、Gaussianの形状を補正する(\cref{sec:covariance-correction})。
  \item \textbf{色・輝度補正}:水面を通した観測による輝度の変化を、Gaussianの色変化で表す補正を導入する(\cref{sec:color-correction})。
\end{itemize}

RA-GSは入力として、カメラパラメータが既知の画像$I_{obs}$を取る。
加えて、カメラに対する水面位置、水の屈折率$n$を既知として与える。

\section{位置補正}\label{sec:position-correction}
まず、カメラ座標系を定義する。カメラ中心を$z$軸上の$(0, 0, H)$、水面を$xy$平面($z=0$)、水面法線ベクトルを$\mathbf{n} = (0, 0, 1)$とする。
ここで、水中の任意のGaussianの中心位置を$\bm{p} = (x, y, z)$ ($z < 0$)とする。
水面に波がなく平坦であると仮定した場合、屈折現象は視線方向に対して回転対称性を有する。
したがって、幾何学的計算を簡略化するため、三次元座標を動径方向距離 $r = \sqrt{x^2 + y^2}$ を用いて2次元の$rz$平面へと射影して議論を行う。
既存手法\cite{westaway2001_PhotograBathy-multiply-n,Woodget2014_PhotograBathy-multiply-n,Dietrich2016_multi-angle-correction,Makris2024_refractive-aware-sfm}では考慮されていないが、あるカメラ位置からの水中の点はある見かけの位置に位置に一意にマッピングされる\cite{nassar1994_ApparentDepth,Missailidis2025_apparentDepth-leading}
(詳細な導出は\cref{sec:apendix-apparent-depth}を参照)。

屈折を考慮した際、カメラから観測されるGaussianの見かけの中心位置(Apparent position)を$\bm{p'} = (x', y', z')$とし、$rz$平面上での座標を$(r', z')$とする。
カメラから$\bm{p'}$へ向かう光線と水面との交点を$(s, 0)$ ($0 \leq s < r$)と定義する。
また、観測角(屈折角)を$\theta_a$、水中角(入射角)を$\theta_w$とし、水の屈折率を$n$、空気の屈折率を1とすると、スネルの法則より次式が成立する:
% \note{空気中から水中の物体を観測する場合、空気中にあるのは「屈折角」です。 どちらが入射角でどちらが屈折角かは、「光がどちらから進んでくるか」で決まります。}  
\begin{equation}\label{eq:snell}
  \sin \theta_a = n \sin \theta_w
\end{equation}

幾何学的拘束条件およびスネルの法則より、視線光線と水面との交点$s$は以下の$s$に関する4次方程式の解$0\leq s < r$として決定される\cite{nassar1994_ApparentDepth}。
\begin{equation}\label{eq:quartic-s}
  \begin{split}
    (1-n^2)s^4 &+ 2(n^2-1)rs^3 \\
    &+ ((1-n^2)r^2 - n^2H^2 + z^2)s^2 \\
    &+ 2n^2H^2rs - n^2H^2r^2 = 0
  \end{split}
\end{equation}

この方程式の物理的に妥当な解$s$は、勾配法あるいはFerrariの公式を用いることで数値的に算出可能である。
交点$s$が求まれば、幾何学的な位置関係およびスネルの法則の微分関係($\triangle IPC, \triangle IP'C', \triangle I'P'C'$における微小変化)を用いることで、見かけの位置$(r', z')$は$\theta_a$および$\theta_w$の関数として以下の閉形式で導出される(\cref{sec:apendix-apparent-depth}を参照)。
\begin{subequations}\label{eq:apparent-position}
  \begin{empheq}[left=\empheqlbrace]{align}
    r' &= r + (n^2 -1) \cdot z \cdot \tan^3 \theta_w \label{eq:r'} \\
    z' &= \frac{1}{n} \cdot \frac{{\cos \theta_a}^3}{{\cos \theta_w}^3} \cdot z \label{eq:z'}
\end{empheq}
\end{subequations}
ここで$z < 0$および$n > 1$,($\theta_a > \theta_w$)であることから、$r' < r$かつ$|z'| < |z|$が常に成立する。
これは、水中の物体が屈折の影響により、実位置よりも「浅く」、かつ「光軸(直下)寄りに」観測されるという物理現象と合致する。
なお、カメラ直下(Nadir view: $r=0$)においては、上式は$z'=z/n$となり、これは従来の航空写真測量等で用いられる近似式\cite{Woodget2014_PhotograBathy-multiply-n}と一致する。

提案手法を3D Gaussian Splattingの学習プロセスに組み込むためには、この座標変換が微分可能でなければならない。
すなわち、実空間上の位置$\bm{p}$に対する見かけの位置$\bm{p'}$の勾配(Jacobian)が必要となる:
\begin{equation}\label{eq:Jacobian}
  J_{app} = \frac{\partial \bm{p'}}{\partial \bm{p}} \in \mathbb{R}^{3 \times 3}
\end{equation}

本研究では、明示的な導出からJacobianを算出した。
