3D Gaussian Splatting (3DGS) は、近年、新規視点合成のみならず、三次元表現として広く普及している手法である \parencite{Kerbl2023ToG_3DGS}。
その特徴は、写実的かつ忠実な三次元シーンの表現力、高速な学習時間、そしてリアルタイムレンダリングにある。
明示的な(Explicit)三次元表現である3DGSは、Visual-SLAM \parencite{Yan2024CVPR_GS-SLAM,Zheng2025CVPR_WildGS-SLAM,Matsuki2024CVPR_GaussianSplattingSLAM}、アバター生成 \parencite{Moreau2024CVPR_HumanGaussianSplatting,Shao2024CVPR_GaussianAvatar}、フィードフォワード型三次元再構成 \parencite{Chen2024ECCV_MVSplatting} など、幅広いタスクへの適用に成功している。
またその応用先は広く、衛星画像からの数値表層モデル(DSM)生成 \parencite{Aira2025CVPR_EOGS}、自動運転 \parencite{Hess2025CVPR_SplatAD,Sandula2025ICRA_GS-Lidar-Fusion}、そして水中三次元再構成 \parencite{li20243DV_watersplatting,Yang2025ICRA_SeaSplat} といった様々な実世界アプリケーションへと拡張されている。

3DGSでは、三次元シーンを多数の三次元ガウス分布(3D Gaussian)の集合で表現している。
3DGSのパイプラインは主に、順レンダリングを行うフォワードパスと、最適化を行うバックワードパスの2つの段階で構成される。

\paragraph{Gaussian Splattingの順レンダリング}
フォワードパスでは、Gaussianの集合を、ラスタライズにより画像平面に投影することで画像を合成する。
ラスタライズ(Rasterization)とは、コンピュータグラフィックスにおいて、3D空間上のデータを2D画像上に投影するプロセスを指す。
3DGSにおいては、楕円体のように表される空間上の三次元ガウス分布を、画像平面上へ叩きつけるイメージから`Splatting'と表現している。

各Gaussianは、
\begin{itemize}
  \item \textbf{中心位置}: $\bm{p} \in \mathbb{R}^3$
  \item \textbf{不透明度}: $\alpha \in [0, 1]$
  \item \textbf{球面調和関数(SH)によって表現される視点依存の色係数}: $\bm{c}(\bm{p}, \bm{t}_i) \in \mathbb{R}^{3}$
  \item \textbf{スケール}: $\bm{s} \in \mathbb{R}^3$と\textbf{回転行列}: $\bm{R} \in SO(3)$から構成される\textbf{三次元共分散行列}: $\bm{\Sigma}^{\mathrm{3D}} \in \mathbb{R}^{3 \times 3}$ 
\end{itemize}
という、パラメータセットによって定義される。
これらのパラメータは、カメラパラメータを推定するSfMで副次的に得られる疎点群を用いて初期化される(\cref{fig:3dgs_pipeline}A)。
共分散行列 $\bm{\Sigma}^{\mathrm{3D}}$ は、スケールベクトル $\bm{s} \in \mathbb{R}^3$ から構成されるスケール対角行列 $\bm{S} \in \mathbb{R}^{3 \times 3}$ と、回転クォータニオン$\bm{q} \in \mathbb{R}^4$ (回転行列 $\bm{R} \in SO(3)$ として表現)を用いて以下のように構成される：
\begin{equation}\label{eq:3dgs-sigma_RssR}
  \bm{\Sigma}^{\mathrm{3D}} = \bm{R} \bm{S} \bm{S}^\top \bm{R}^\top
\end{equation}
点 $\bm{x} \in \mathbb{R}^3$ に対する対応する非正規化ガウス分布関数は以下で与えられる：
\begin{equation}\label{eq:3dgs-G(x)}
  G(\bm{x}) = 
    \exp \left( -\frac{1}{2} (\bm{x} - \bm{p})^T \left({\bm{\Sigma}^{3D}}\right)^{-1} (\bm{x} - \bm{p}) \right)
\end{equation}
フォワードパスにおいて、あるカメラ視点からの画像をレンダリングするために、これらのガウス分布はまず外部パラメータ行列 $[\bm{W} | \bm{t}]$ を用いてワールド座標系からカメラ座標系へと変換される。
ガウス分布の中心位置 $\bm{p}$ と三次元共分散行列は以下のように更新される：
\begin{align*}
  &\bm{p}_\mathrm{cam} = \bm{W}\bm{p} + \bm{t} \\
  &\bm{\Sigma}^{3D}_\mathrm{cam} = \bm{W} \bm{\Sigma}^{3D} \bm{W}^\top
\end{align*} 
ここで、$\bm{W}_\mathrm{view} \in \mathbb{R}^{3 \times 3}$ は視点回転行列、
$\bm{t} \in \mathbb{R}^3$ は平行移動ベクトルである。
Zwickerら\cite{Zwicker2001_EWA-volume-splatting} の提案した射影手法に従い、カメラ空間における三次元共分散行列 $\Sigma_{cam}^{3D}$ は2次元画像平面へと射影される。
これには透視投影のアフィン近似のヤコビ行列 $\bm{J}$ を用いることで、2次元共分散行列 $\bm{\Sigma}^{\mathrm{2D}}$ が得られる：
\begin{equation}\label{eq:3dgs-affine-projection}
\Sigma^\mathrm{2D} = \bm{J} \Sigma^{\mathrm{3D}}_\mathrm{cam} \bm{J}^\top
\end{equation}
各ピクセルの最終的なRGB値 $\bm{\Gamma} \in \mathbb{R}^{3}$ は、射影されたGaussianをボリュームレンダリングすることにより得られる。
ピクセルと重なるGaussianの集合は、まず深度に基づいて手前から奥へとソートされ、視点依存色が以下のように累積される:
\begin{align}\label{eq:3dgs-alpha-blending}
  \bm{\Gamma}(\bm{x}) = \sum_{k=1}^{K} \bm{c}_k \alpha^{\text{pixel}}_k \prod_{j=1}^{k-1} (1-\alpha^{\text{pixel}}_j) \\
  \quad \text{where} \quad \alpha^{\text{pixel}}_k = \alpha_k G_k^{\mathrm{2D}} \notag
\end{align}
ここで、$k$ はピクセルに重なる整列されたGaussianの集合のインデックスである。

一般に、ラスタライズは、NeRF(\cref{subsec:nerf})で示したような視線光線に対して各々サンプリングを行うことで画素値を求めるレイトレーシング手法よりも高速である。
3DGSでは、画面を小さなタイルに分割し、関係のあるガウシアンだけを効率よく計算するTile-Basedラスタライズを用いることで、100 fps以上の高速なリアルタイムレンダリングを実現している。


\paragraph{Gaussian Splattingの逆レンダリング}
バックワードパスでは、最適化により測光誤差(Photometric loss)を最小化する。
これは $\mathcal{L}_1 (\Gamma, \Gamma_{gt})$ 損失と D-SSIM 損失 $\mathcal{L}_\mathrm{D-SSIM} (\Gamma, \Gamma_{gt})$ \parencite{Zhou2004_SSIM} の加重和である：
\begin{equation}\label{eq:loss-function}
  \mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda \mathcal{L}_\mathrm{D-SSIM}
\end{equation}
したがって、Analysis-by-Synthesis(\cref{subsec:differentiable-rendering})によって最適化問題は以下のように定式化される：
\begin{equation}\label{eq:optimization}
  \underset{p, R, s, c, \alpha}{\textrm{argmin}} \quad \mathcal{L} = \mathcal{L}(\bm{\Gamma}, \bm{\Gamma_{gt}}) 
\end{equation}
この定式化により、パイプライン全体が完全微分可能となり、パラメータ $\Theta = \{\bm{p}, \bm{R}, \bm{s}, \bm{c}, \alpha\}$ はAdamなどの勾配降下法\parencite{Adam}によって最適化可能となる。
(\cref{fig:3dgs_pipeline}B)

\paragraph{Adaptive Density Control}
これらの勾配降下法のみでは、特に観測視点が少ない箇所(Few Shot Area)などで、シーンの多視点からの一貫性に欠ける局所最適解に陥りやすい。
これを解決するために3DGSではAdaptive Density Control(ADC)というヒューリスティックな手法が導入されている。
あるGaussianに関して、その2D平面や3D空間における位置に対する誤差勾配$\frac{\partial \mathcal{L}}{\partial \bm{p}}$が大きい場合、そのGaussianは幾何的な誤差の大きいものであるという推察に基づき、
分割(Split)、複製(Clone)、消去(Prune)のいずれかの操作を行う。
位置誤差勾配がある閾値を超え、さらにシーンに対してGaussianが大きい場合は分割、小さい場合は複製を行う。
また、不透明度$\alpha$が小さいGaussianも消去する。
効果的にシーンに寄与しないGaussianを判別するため、一定のイテレーションごとにシーンのGaussianの不透明度を一様に透明に近くリセットすることで、その後不透明度が向上しないGaussianを削除できる。

    Adaptive Density Control(ADC)の操作。

    Gaussianに流れる位置誤差勾配が大きい場合、または、サイズが小さいGaussianに対しては、複製を行う。
    サイズが大きいGaussianに対しては、分割を行うことで、適切なサイズのガウス分布でシーンを満たす。
    }

\begin{center}
  \begin{minipage}{0.8\linewidth}
    \begin{algorithm}[H]\label{alg:3dgs-adc}
      \caption{
        3DGS\cite{Kerbl2023ToG_3DGS}におけるAdaptive Density Controlアルゴリズム。
        \cite{Grubert2025VISAPP_improve-ADC}より引用。
        }
      \SetAlgoLined
      \DontPrintSemicolon
      
      \textbf{Data:} Scene of Gaussians $G$ \\
      \For{$G_k \in G$}{
          \Comment{Densification}
          \If{$\tau_k \geq T_{grad}$}{
              \If{$\max(s_k) > P_{dense} \cdot e_{scene}$}{
                  splitGaussian($G_k$)\;
              }
              \Else{
                  cloneGaussian($G_k$)\;
              }
          }
          
          \Comment{Opacity Pruning}
          \If{$\alpha_k < \alpha_{min}$}{
              pruneGaussian($G_k$)\;
          }
          
          \Comment{Size Pruning}
          \If{$\max(s_k) > 0.1 \cdot e_{scene}$}{
              pruneGaussian($G_k$)\;
          }
      }
    \end{algorithm}
  \end{minipage}
\end{center}

ここで、
$\tau_k$ は二次元位置誤差勾配の平均値、
$P_{dense}$ はシーンのスケールに応じた分割･複製のハイパーパラメータ、
$T_{grad}$ は位置誤差勾配の閾値ハイパーパラメータ、
$e_{scene}$ はシーンの範囲、
$\alpha_{min}$ は消去を行うための不透明度に関するハイパーパラメータである。

% Adam \parencite{Adam} を用いた~ と言っていたがこれは、Implplementationで言及すること
3DGSの最適化に要する時間は、30kのイテレーションにおいて1時間以内となり、当時NVSのSotaであったMip-NeRF360 \parencite{Barron2022CVPR_Mip-NeRF360} に画質指標で匹敵しながら、10倍以上の高速化を達成した。





\subsection{2D Gaussian Splatting}\label{sec:2DGS}
2D Gaussian Splatting(2DGS) \parencite{Huang2024SIGGRAPH_2DGS}は、測光誤差に関する最適化による外観の一貫性に特化した3DGSに対し、幾何的な一貫性を向上させることを目的とした派生手法である。
三次元シーンで観測される放射輝度(Radiance)は、環境光が物体表面で反射することで観測されるという前提から、各Gaussianを物体表面に整列するように最適化を行う。
MVSなどのGeometric Reconstructionの一種とも言える。

2DGSの3DGSとの違いは、主に以下の3点である:
\begin{itemize}
  \item 平らな2次元ガウス分布(Surfel)による三次元シーン表現
  \item 正確な透視投影(Perspective-accurate)な2D Gaussianの2次元画像平面への射影
  \item 幾何的な整合性を高める正則化の導入
\end{itemize}

2DGSにおいて、シーンは平らな2次元ガウス分布(Surfel:2D-oriented planar Gaussian disks)の集合として表現される。
3DGSに比較し、スケーリングベクトル $\bm{s}$のうち最小の成分を0と表現したSurfelとして表現する。
よって、2DGSのプリミティブは、中心位置$\bm{p}_k$、主方向ベクトル$\bm{t}_u$と$\bm{t}_v$、それに対応するスケール$\bm{s} = (s_u, s_v)$によって表現される。
(回転行列$\bm{R}_k$、不透明度$\alpha_k$と視線依存色$\bm{c}_k$は3DGSと同様である。)


具体的には、3D空間内の二次元ガウス分布は、ローカルな接平面 $(u, v)$ 上で定義され、その幾何学的形状は同次変換行列 $\bm{H} \in \mathbb{R}^{4 \times 4}$ を用いて以下のようにパラメータ化される。

\begin{equation}\label{eq:2dgs-plane-def}
  \bm{H} = 
  \begin{bmatrix}
    s_u \bm{t}_u & s_v \bm{t}_v & \bm{0} & \bm{p}_k \\
    0 & 0 & 0 & 1
  \end{bmatrix}
\end{equation}

ここで、ローカル座標 $\bm{u} = (u, v)$ におけるガウス分布の強度は、標準的な2次元ガウス関数として定義される。
\begin{equation}\label{eq:2dgs_uv-space}
  G(\bm{u}) = \exp\left( - \frac{u^2 + v^2}{2} \right)
\end{equation}

\paragraph{視線との交差判定による正確な透視投影}
3DGSが採用しているアフィン近似による投影(\cref{eq:3dgs-affine-projection})は、ガウス分布の中心から離れるにつれて近似誤差が増大し、また、視点によって深度が不整合するという問題がある。
これに対し2DGSは、視線と2D Gaussianの交差判定(Ray-Splat Intersection)を明示的に計算することで、正しい透視投影を実現する。

スクリーン空間上のピクセル座標 $\bm{x} = (x, y)$ を通る視線レイは、三次元空間において直交する2つの平面(x-planeとy-plane)の交線として定義できる。
これを同次座標系の4次元平面ベクトル $\bm{h}_x = (-1, 0, 0, x)^\top, \bm{h}_y = (0, -1, 0, y)^\top$ として表現し、これらをワールド空間からスクリーン空間への変換行列 $\bm{W}$ と、先述のローカル変換行列 $\bm{H}$ を用いてガウス分布のローカル座標系へ逆変換する。
ここで、平面の変換には逆転置行列 $(\bm{W}\bm{H})^{-\top}$ を用いるが、これにより明示的な逆行列計算を回避し、数値的な安定性を保つことができる。

\begin{equation}\label{eq:2dgs-h-transform}
  \bm{h}_u = (\bm{W}\bm{H})^\top \bm{h}_x, \quad \bm{h}_v = (\bm{W}\bm{H})^\top \bm{h}_y
\end{equation}

この変換された平面 $\bm{h}_u, \bm{h}_v$ と、ローカル平面上の点 $(u, v, 1, 1)^\top$ との内積が0になるという条件から、交差点 $\bm{u}(\bm{x})$ を以下の閉形式で高速に求めることができる。

\begin{equation}\label{eq:2dgs-intersection}
  \bm{u}(\bm{x}) = \frac{1}{\bm{h}_u^3 \bm{h}_v^4 - \bm{h}_u^4 \bm{h}_v^3} 
  \begin{pmatrix}
    \bm{h}_u^2 \bm{h}_v^4 - \bm{h}_u^4 \bm{h}_v^2 \\
    \bm{h}_u^4 \bm{h}_v^1 - \bm{h}_u^1 \bm{h}_v^4
  \end{pmatrix}
\end{equation}
ここで $\bm{h}^i$ はベクトルの第 $i$ 成分を表す。
これにより得られた $\bm{u}(\bm{x})$ を用いて $G(\bm{u}(\bm{x}))$ (\cref{eq:2dgs_uv-space})を評価することで、正確なレンダリングが可能となる。

% これを防ぐため、2DGSではローパスフィルタ $\sigma$ を導入し、スクリーン空間での最小サイズを保証する以下のクリッピング処理を行う。
% \begin{equation}

\paragraph{幾何学的な一貫性を高める正則化}
2DGSは物体表面に適用しやすい面的なプリミティブで表現されるが、測光誤差のみでは三次元再構成特有の不定性によりノイズの多い表面形状に収束する傾向がある。
そこで、幾何学的精度を向上させるために\cite{Barron2022CVPR_Mip-NeRF360}で提案された2つ正則化項をGSフレームワークに導入する。

一つ目は \textbf{深度歪み正則化} ($\mathcal{L}_d$) である。
3DGSのボリュームレンダリングは、レイ上の交点間の距離を考慮しないため、ガウス分布が前後に散らばるアーティファクトが生じやすい。
そこで、2DGSでは、レイ上の交差点深度 $z_i$ とブレンディング重み $\omega_i$ を用いて、寄与の高いGaussian同士のの深度距離を最小化するように制約をかける。
これにより、物体表面が高密に、明確に表現されるようになる。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.7\textwidth]{figure/40_prelim/2dgs_regulatization.png}
  \caption{
    2DGSの正則化項の効果。
    \cite{Huang2024SIGGRAPH_2DGS}より引用。
    左から順に、入力画像、法線整合性正則化なし、深度歪み正則化なし、そして両方の正則化を適用した2DGSの結果である。
    それぞれ法線マップで表面形状を可視化している。
    法線整合性正則化を適用しない場合、表面の法線方向にノイズが生じる。
    一方、深度歪み正則化を省略すると、法線マップがぼやけたものとなる。
    両方の正則化を併用することで、鋭く滑らかな表面形状を正確に再構成できている。
    }
    \label{fig:2dgs_regulatization}
\end{figure}

\begin{equation}
  \mathcal{L}_d = \sum_{i, j} \omega_i \omega_j |z_i - z_j|
\end{equation}

二つ目は \textbf{法線整合性正則化} ($\mathcal{L}_n$) である。
2DGSではプリミティブ自身が法線ベクトル $\bm{n}_i = \bm{t}_u \times \bm{t}_v$ を持っている。
ここで $\times$ はベクトルの外積演算を表す。
この明示的な法線と、レンダリングされた深度マップから推定される法線 $\bm{N}$(深度の勾配 $\nabla \bm{D}$ から算出)との整合性を取ることで、滑らかな表面再構成を強制する。

\begin{equation}
  \mathcal{L}_n = \sum_{i} \omega_i (1 - \bm{n}_i^\top \bm{N})
\end{equation}

最終的な損失関数は、3DGSの測光誤差(\cref{eq:loss-function})に加え、これらの正則化項を加重和したものである。
これらの幾何学的制約により、2DGSからは高精細かつ滑らかなメッシュ抽出が可能となる一方で、3DGSと同等のレンダリング速度と画質を維持している。


しかしながら、これらのGaussian Splattingのパイプラインはピンホールカメラモデルを基にした透視投影に依存しており、光が直線的に進むことを根本的な前提としている。
この前提は、空気と水の境界での屈折が幾何学的矛盾を引き起こすような複数の媒質が介在する環境においては成立しない。
この制限にもかかわらず、GSの明示的な三次元表現は、屈折の法則を数学的に定式化し、シーン表現の幾何学的パラメータそのものに直接適用することを可能とする。
一方で、GSではラスタライズによってレンダリングされるため、レイトレーシングのように視線の方向の変更による屈折の影響のモデル化\cite{Zhan2023CVPR_NeRFrac}ができない、という困難も生じる。
